# Fase 05.03 — Motor Aegis (Compilador Analítico)

**Aegis** es el transpilador ciego del ecosistema. Su responsabilidad única (SRP) es consumir el árbol inmutable de lógica que orquesta Janus (**Janus AST IR**) y transmutarlo algebraicamente hacia el motor de almacenamiento aplicable: **Datalog (Datahike)** para cargas OLTP o dialectos SQL de tipo **Athena / HoneySQL** para cargas OLAP.

## 1. Naturaleza Funcional y "Ciega"

Aegis posee una naturaleza transaccionalmente libre de ambigüedades:
- **No posee Estado:** Todas sus funciones son puras. No almacena contexto global.
- **Sin conocimiento de Seguridad:** Aegis asume que el `AST IR` provisto por Janus ya contiene las constricciones ABAC y los anclajes de Row-Level Security requeridos (`:permitted-locations`, `:permitted-assets`). Su trabajo no es autorizar, su trabajo es mapear la geometría estructural.
- **Data-Driven puro:** Emplea mapas EDN/Clojure sin Side-Effects directos o colaterales que muten el entorno exterior.

## 2. Transpilación a Datalog (OLTP Datahike)

Cuando el orquestador Janus determina que la consulta debe procesarse contra el almacén local relacional (Datahike), Aegis se encarga de convertir el `AST IR` en un grafo optimizado de lectura.

### 2.1 — Estrategia de Topología Mixta (`Query` + `Pull`)
Aegis no abusa de mapeos relacionales intrínsecos de Datahike. Adopta una técnica de segmentación híbrida:
1. **Filtros por Query:** Convierte las aserciones lógicas del `:where` estipulado en el `AST IR` en predicados eficientes de Datalog `[:find [?e ...] :where [?e :attribute ?value] ...]`. El propósito inicial es extraer una subred selectiva de identificadores (`entity ids`).
2. **Proyección por Pull:** Toma el nodo `:select` del IR (estructura Graph/GraphQL-like) y formula especificaciones validas para el api de `d/pull`. Luego efectúa un barrido ultra veloz desde el snapshot inmutable actual de Datahike para rellenar los atributos colaterales referenciados de cada UUID en tiempo O(1).

### 2.2 — Prevención de Explosiones Cartesianas
Evitando la colisión en jerarquías profundas o subgrafos iterativos, Aegis estructura sus matrices Datalog ordenando cláusulas (variables de mayor selectividad como `tenant_id` posicionado prioritariamente).

## 3. Transpilación a SQL (OLAP Athena / Iceberg)

Si el `AST IR` demanda reportes sobre el Data Lake histórico o consultas cruzadas persistentes:
- **Adopción de HoneySQL:** Aegis transpila dinámicamente el IR de Janus a un mapa seguro en Clojure interpretado por `seancorfield/honeysql`. Se blinda a la aplicación contra inyecciones SQL nativas.
- **Particionamiento Mandatorio S3:** Reconociendo que Athena procesa archivos particionados *Iceberg / Parquet*, Aegis inserta obligatoriamente directrices de *Zone Map* o *Partition Pruning* (como `tenant_id` y sub-paths temporales calculados de fecha/hora). Jamás se emite una query de tipo *full-scan root* al depósito S3.

## 4. Filosofía Zero-Exception y Server-Side Lazy Streams

El retorno transpilado hacia el llamador orquestador (Janus) hereda idénticamente la arquitectura principal del Motor:
- **Respuesta Railway:** Aegis aborta la consulta ante el mínimo incumplimiento sintáctico y lo canaliza elegantemente empacando un `[:error metadata]`. Todo bloque `try-catch` es interceptado a gran nivel como Error de Componente.
- **Iteradores Perezosos:** En caso de éxito, el motor nunca inunda la tabla RAM con arrays precalculados. Regresa `[:ok lazy-iterator]`. Janus recibe un puntero perezoso (`lazy-seq` nativo clojure) y procesa las conversiones subyacentes con técnica de fragmentación (*Server-Side Chunking*) sobre canales gRPC, sosteniendo métricas estables de Heap incluso resolviendo un millón de tuplas de red.

---

## 5. Simulación Estricta y Entornos Locales

La validación funcional unitaria se encauza bajo la topología SQL de aislamiento, limitando agresiones directas de costos:
- Aegis confía primariamente en inyecciones in-memory de **DuckDB** para homologar analítica sintáctica Trino/Athena antes del pull de CI/CD.
- Validaciones en pipelines de TDD asimilan repositorios Datahike de memoria pura ramificada efímera (`:schema-flex`).
