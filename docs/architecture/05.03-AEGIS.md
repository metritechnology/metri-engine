# Fase 05.03 - Motor Aegis (Compilador Analítico)

**Aegis** es el transpilador ciego, el trabajador puro de la geometría de datos. No expone APIs ni entiende de topologías de seguridad de tokens. Su ciclo de vida es absoluto: Recibe el `Safe ATS` validado de Janus y dictamina si transpilar a dialecto **Datalog (OLTP)** o ejecutar delegación **HoneySQL a Trino / Athena (OLAP)**.

## 1. MQL (Metri Query Language)
Aegis trabaja sobre el contrato V3.7 interno. Resuelve la ambigüedad paramétrica eliminando `select-tree` anticuados por cláusulas `select` lineales y de orden predecible, facilitando transformaciones funcionales AST-to-Datalog (anidadas en `src/metri/engine/aegis/`).

## 2. Transpilación Datalog (Datahike Local)
Si las matrices carecen de agrupaciones analíticas severas:
- **Mitigación Pathfinding Dijkstra:** Aegis transacciona `FilterNodes` con algoritmos Pathfinding de matriz topológica sobre el grafo, ordenando los Joins relacionales al Datahike para minimizar los escaneos en O(1) de memoria, garantizando la abolición del Ciclo Cartesiano infinito.

## 3. Transpilación HoneySQL (Iceberg Trino/Athena)
Si el ATS demanda métricas de Big Data:
- Compila HoneySQL dinámicamente configurando el `TRINO_JDBC_URI`.
- Inyecta clausuras *HATEOAS* de respuesta y fuerza la partición de índices (Zone Map Awareness) al enviar cláusulas temporales forzosas de particionamiento S3 en el `WHERE`.

## 4. Filosofía Zero-Exception
Si ocurren Timeout concurrentes de Athena o Datahike rechaza la concurrencia:
- Aegis no detona el JVM. Captura un Result Mónad `[:error CON_409]` (colisión) y lo retorna limpio al padre, levantando un span de OpenTelemetry intrínseco. El orquestador Janus retoma el fallo y decide la reintención o caída delegada.

## 5. Simulación y Test de Élite Aislada
Aegis emplea sub-motores efímeros en RAM como **DuckDB local** como simulador de Trino para las pruebas unitarias de su transpilación matemática de métricas en pipeline CI, evadiendo la necesidad agresiva de pagar instancias EC2/Athena por cada Git Commit. Testea rígidamente la deduplicación de JOINs HoneySQL.
