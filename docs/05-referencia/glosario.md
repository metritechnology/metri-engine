# Glosario Canónico de `metri-engine`

Diccionario de términos arquitectónicos, matemáticos, criptográficos y de dominio utilizados en el código fuente (`src/`) y en la documentación de `metri-engine`.

| Término | Módulo Principal | Definición Técnica en `metri-engine` |
| :--- | :--- | :--- |
| **ABAC (Attribute-Based Access Control)** | `src/cedar/` | Modelo de control de acceso basado en atributos del principal (`PrincipalData`), del recurso (`MetriResource`) y del contexto, evaluado mediante Cedar Policy 3. |
| **Aegis** | `src/aegis/` | Subsistema de ejecución de consultas y evaluación matemática sobre el AST IR: integra el ejecutor vectorizado `.mbf`, el ejecutor transaccional OLTP y el motor de fórmulas sandboxeado. |
| **AST IR (Intermediate Representation)** | `src/janus/` · `src/aegis/` | Representación intermedia tipada de una consulta, serializada en formato binario zero-copy mediante FlatBuffers (`src/janus/janus_ir_ast.fbs`). |
| **AVET / AEVT / EAVT / VAET** | `src/eav/` · `src/mbf/` | Cuatro perspectivas de indexación sobre los datoms: Entidad-Atributo-Valor-Tx (`EAVT`), Atributo-Entidad-Valor-Tx (`AEVT`), Atributo-Valor-Entidad-Tx (`AVET`, unicidad y rangos) y Valor-Atributo-Entidad-Tx (`VAET`, referencias inversas y grafos). |
| **Base36 Estocástico (`stochastic_base36`)** | `src/codice/base36.rs` | Generador criptográfico (`CSPRNG`) de códigos alfanuméricos compactos no predecibles (ej. `A-K92MXA1`) con política *zero-drop*. |
| **CAS (Compare-And-Swap)** | `src/mbf/storage.rs` · `src/mbf/tx/` | Protocolo de control de concurrencia optimista sobre S3 mediante cabeceras condicionales `If-Match: <ETag>`, garantizando serializabilidad ACID sin bloqueos distribuidos. |
| **Cedar Policy** | `src/cedar/` · `config/policies/` | Motor de políticas de seguridad de código abierto desarrollado por AWS, embebido en `metri-engine` como Punto de Decisión de Políticas (PDP) *fail-closed*. |
| **Chimp128** | `src/mbf/zones/iot_timeseries.rs` | Algoritmo de compresión sin pérdida basado en XOR para series temporales de punto flotante (`f64`), combinado con *Delta-of-Delta* para marcas de tiempo IoT. |
| **Códice (`CodeRegistry`)** | `src/codice/` · `config/models/` | Registro inmutable y única fuente de verdad (SSOT) de los 60 modelos de datos JSON del dominio, compilado en memoria (`OnceLock`) durante el arranque. |
| **CompositeCursor** | `src/aegis/pagination.rs` | Cursor opaco codificado en Base64/MessagePack que preserva la posición exacta de paginación en consultas multi-entidad o multi-índice. |
| **CompositeTransact** | `src/grpc/handlers/composite.rs` | Operación gRPC que escribe de forma atómica una entidad raíz (ej. `work_order`) junto con todas sus entidades hijas (`work_order_procedure`, `work_order_task`, etc.) en una sola transacción ACID. |
| **CSR (Compressed Sparse Row) + Euler `[tin, tout]`** | `src/mbf/zones/csr_graph.rs` | Representación compacta de grafos y árboles jerárquicos ISA-95 donde cada nodo recibe su intervalo de entrada/salida de recorrido de Euler, permitiendo resolver consultas de subárbol en $O(1)$ mediante `tin >= root.tin && tout <= root.tout`. |
| **Datom** | `src/eav/types/datom.rs` | Unidad atómica e inmutable de información en el motor: tupla `[entidad, atributo, valor, tx, op]` donde `op` es `Assert` (afirmación) o `Retract` (retracción). |
| **DomainError / ErrorCode** | `src/domain/errors.rs` | Tipo de error canónico único del motor; cada variante de `ErrorCode` mantiene correspondencia 1:1 con `config/errors/error_catalog.toml`. |
| **Fail-Closed (Fallo Cerrado)** | `src/cedar/` · `src/domain/config.rs` | Principio de seguridad Zero-Trust según el cual cualquier incertidumbre, dato faltante, token inválido o error de evaluación produce denegación inmediata de acceso o aborto del arranque. |
| **Fenwick Tree (`FenwickPrefixSum128`)** | `src/mbf/zones/financial_ledger.rs` | Árbol binario indexado sobre enteros de 128 bits que permite calcular sumas prefijas y flujos contables por rango de tiempo en $O(\log N)$ u $O(1)$ por bloque. |
| **FixedDecimal128** | `src/mbf/zones/financial_ledger.rs` | Representación numérica de punto fijo en 128 bits (`i128` con escala $10^6$) que elimina el error de redondeo de punto flotante IEEE 754 en contabilidad, inventario y divisas. |
| **HOT_HEAD.mbf** | `src/mbf/tx/mod.rs` | Manifiesto transaccional caliente por tenant que consolida la ventana MVCC reciente (L0), reclamaciones de unicidad (`UniqueClaim`), contadores de secuencia, cuotas y punteros a segmentos `.mbf`. |
| **HTAP (Hybrid Transactional/Analytical Processing)** | `src/mbf/` | Arquitectura que ejecuta en el mismo proceso y sobre el mismo formato binario (`.mbf`) tanto transacciones operativas ACID (OLTP) como consultas analíticas vectorizadas de Business Intelligence (OLAP). |
| **IOP (Ingest Orchestration Pipeline)** | `src/iop/` | Pipeline ferroviario (*Railway*) que orquesta toda mutación entrante ejecutando en secuencia estricta: `CedarStep` (autorización) $\rightarrow$ `QuotaStep` (débito atómico) $\rightarrow$ `JanusStep` (escritura y saga). |
| **ISA-95** | `config/models/location.json` | Estándar internacional para la jerarquía física de activos y plantas industriales (Empresa $\rightarrow$ Sitio $\rightarrow$ Área $\rightarrow$ Celda/Línea $\rightarrow$ Unidad/Activo). |
| **Janus** | `src/janus/` | Subsistema que implementa el Camino de Lectura (*Read Path*): normaliza solicitudes gRPC, valida esquemas, selecciona el plan de ejecución, inyecta cláusulas ABAC y compila el AST IR en FlatBuffers. |
| **Janus Router** | `src/janus_router/` | Subsistema que implementa el Camino de Escritura (*Write Path*): enruta mutaciones hacia el canal transaccional `.mbf`, proyecta sagas declarativas (`scheduled_job`) y genera ULIDs monotónicos. |
| **KLL Sketch** | `src/mbf/zones/bi_synopses.rs` | Estructura probabilística compacta de Karnin-Lang-Liberty que estima cuantiles y percentiles ($P_{50}, P_{95}, P_{99}$) en una sola pasada con cota de error garantizada. |
| **Metri Vortex (`.mbf`)** | `src/mbf/` | Motor de almacenamiento y ejecución binaria propio (*Metri Binary Format*), estructurado en bloques alineados a 64 bytes (`#[repr(C, align(64))]`) y 8 zonas especializadas. |
| **Minor Units (`*_cents`)** | `config/models/` | Convención obligatoria del Códice según la cual todo importe monetario se almacena como entero exacto en la unidad menor de la divisa (céntimos) acompañado de un atributo `currency` ISO 4217. |
| **Moira** | `src/eda/moira.rs` | Motor de drenaje del *Transactional Outbox* y evaluación por lotes de reglas de enrutamiento de eventos (`event_routing_rule`) hacia EventBridge y SQS. |
| **MVCC (Multi-Version Concurrency Control)** | `src/mbf/zones/pax_mvcc.rs` | Control de concurrencia multiversión mediante vectores bi-temporales `tx_assert` y `tx_retract`, permitiendo lecturas consistentes (*snapshot isolation*) y consultas históricas *as-of* sin bloquear escrituras. |
| **PAX (Partition Attributes Across)** | `src/mbf/zones/pax_mvcc.rs` | Disposición física híbrida que agrupa registros en páginas de tamaño fijo y organiza los atributos de forma columnar dentro de cada página para maximizar la localidad de caché CPU y vectorización SIMD. |
| **Pébay / Welford-Chan** | `src/mbf/zones/bi_synopses.rs` | Algoritmos numéricamente estables de una sola pasada y fusionables en paralelo para calcular media, varianza ($M_2$), asimetría ($M_3$ *skewness*), curtosis ($M_4$) y co-momentos bivariados. |
| **QuotaLedger** | `src/quota/ledger.rs` | Libro mayor atómico por tenant que verifica el límite (`max_limit`) y debita el consumo en una única operación condicional, eliminando condiciones de carrera entre lecturas y escrituras concurrentes. |
| **Railway Pattern** | `src/domain/pipeline/result.rs` | Patrón funcional de encadenamiento de operaciones sobre `DomainResult<T>` donde el primer error cortocircuita limpiamente el pipeline sin usar excepciones ni `unwrap()`. |
| **Saga Declarativa (`shadow_sagas_mapping`)** | `src/janus_router/saga.rs` | Mecanismo mediante el cual la creación o actualización de entidades de planificación (`preventive_maintenance`, `reminder`) proyecta automáticamente su `scheduled_job` dentro de la misma transacción ACID. |
| **Sherlog** | `src/iop/sherlog.rs` | Subsistema forense que captura fallos del pipeline de ingesta, censura atributos sensibles (`sensitive: true`) y publica diagnósticos estructurados (`domain_fault`). |
| **Tenant Maestro (`system`)** | `src/cedar/rules.rs` | Identificador reservado del tenant de administración de plataforma, sujeto a reglas de censura Zero-Trust (`SystemSecurityRules`) e inaccesible para tenants ordinarios. |
| **TenantGuard** | `src/infrastructure/tenant_guard.rs` | Guardián de frontera que valida que toda operación de almacenamiento lleve un `tenant_id` válido y coincidente con el contexto autenticado. |
| **Transactional Outbox** | `src/eav/writer/outbox.rs` | Patrón de consistencia en el cual el evento de dominio (`outbox_event`) se inserta en la misma transacción ACID que los datoms de negocio, garantizando entrega *at-least-once* sin pérdida de eventos. |
| **ULID Monotónico** | `src/janus_router/ulid.rs` | Identificador único universalmente ordenable de 128 bits (48 bits de timestamp en ms + 80 bits de entropía monotónica) que preserva el orden estricto de creación incluso dentro del mismo milisegundo. |
| **UniqueClaim** | `src/eav/writer/constraints/unique_claim.rs` | Registro centinela insertado dentro de la transacción ACID para garantizar unicidad de atributos (`unique: "tenant"` o `"identity"`) sin condiciones de carrera. |
